### A/В-тестирование новой механики оплаты на сайте

**Стек:** Python, Pandas, Numpy, Scipy 

---

#### Описание:
В ходе тестирования одной гипотезы целевой группе была предложена новая механика оплаты услуг на сайте, у контрольной группы оставалась базовая механика. Проанализировать итоги эксперимента и сделать вывод, стоит ли запускать новую механику оплаты на всех пользователей.

#### Цель проекта:
Проанализировать итоги эксперимента; определить требуемые метрики; определить, есть ли различия в показателях, являются ли они статистически значимыми; сделать вывод, стоит ли запускать новую механику оплаты.

#### Данные:
groups.csv – файл с информацией о принадлежности пользователя к контрольной или экспериментальной группе (А – контроль, B – целевая группа).
| Название поля |	Описание |
| :--- | :--- |
| id	| идентификатор пользователя |
| grp	| группа |

groups_add.csv – дополнительный файл с пользователями, который прислали спустя 2 дня после передачи данных.
| Название поля |	Описание |
| :--- | :--- |
| id	| идентификатор пользователя |
| grp	| группа |

active_studs.csv – файл с информацией о пользователях, которые зашли на платформу в дни проведения эксперимента.
| Название поля |	Описание |
| :--- | :--- |
| student_id | идентификатор пользователя |

checks.csv – файл с информацией об оплатах пользователей в дни проведения эксперимента.
| Название поля |	Описание |
| :--- | :--- |
| student_id | идентификатор пользователя |
| rev | сумма |

---

#### Результаты проекта:
Предобработка данных и очистка:
- Анализировались данные 8 341 активного пользователя (1 538 в группе A и 6 803 в группе B)
- Исключена аномальная группа из 149 пользователей (28% всех оплат), которые оплатили услугу, но не заходили на платформу в дни эксперимента (на них новая механика повлиять не могла)
- Проведена SRM-проверка (Sample Ratio Mismatch): хи-квадрат показал p = 0.0037 < 0.05, что указывает на небольшое, но статистически значимое отклонение долей активных пользователей от исходного разбиения (доля группы A составила 18.4% вместо 19.7%)

Проверка условий и выбор статистических тестов:
- Проверка на нормальность (критерий Шапиро-Уилка для ARPPU и Д’Агостино-Пирсона для ARPU) показала p < 0.05 — распределения в обоих случаях не нормальные
- Тест Левена подтвердил равенство дисперсий в группах для ARPPU (p около 0.08) и ARPU (p около 0.22)
- Для оценки бинарной конверсии (CR) выбран критерий хи-квадрат; для денежных показателей (ARPPU, ARPU) — бутстрап (основной) и t-тест Уэлча (подтверждающий)

Выявленные особенности данных:
- В группе B обнаружено 128 оплат ровно на 1 900 руб. (~40% платящих группы B), которых нет в группе A. Это свидетельствует о том, что новая механика активно продвигает конкретный тариф за 1 900 руб., увеличивая средний чек

Итоговое решение по исследованию:
- Механику запускаем с последующим отслеживанием метрик. Новая механика увеличивает сумму оплаты у платящих клиентов (ARPPU), не оказывая статистически значимого негативного влияния на конверсию, однако требует дальнейшего мониторинга показателей и уточнения структуры списаний
